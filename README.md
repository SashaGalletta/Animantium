
# Animantium — The Study of Life

Animantium is a student-created Biology learning website designed
to explain Cambridge IGCSE Biology 0610 topics in a clear,
detailed, and visual way.

## About the project

Created by Narella Galletta, Animantium aims to make Biology
easier to understand through explanations and original illustrations.

## Features

- A clickable index of Biology topics
- Individual pages for each topic
- Original illustrations created by the author
- Learning resources organised around the syllabus

## Status

The website is a work in progress. Lessons and illustrations
will be added gradually.
